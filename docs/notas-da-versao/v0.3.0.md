## Novidades

- **Proxy para as telas de jogo** (⚙ Configurações › Proxy): um proxy para o app todo (`http`, `https` ou `socks5`), com usuário e senha opcionais no `http`/`https`. Vale para todas as telas e para os popups de login (Discord/Google), e é aplicado antes de a tela carregar o jogo. Mudar o proxy com o app aberto recarrega as telas, sem reiniciar.
  - **Testar proxy** mostra o IP de saída visto pela internet antes de salvar, ou o motivo do erro.
  - **Sem vazamento**: com o proxy ligado, se ele cair ou recusar a senha, as telas ficam sem conexão; nunca saem pelo IP direto. O WebRTC das telas não usa UDP fora do proxy.
  - A senha não volta a aparecer na tela, não vai para logs nem para o Discord e não fica no `config.json`.
  - `socks5` com usuário e senha não é suportado pelo Chromium: a tela recusa essa combinação e explica.
  - O webhook do Discord, a checagem de atualização e o download de extensões saem direto, sem o proxy.
  - O proxy não muda nenhum limite de contas: o aviso de mais de 4 telas do Pokeidle continua igual.
- **Telas de jogo em sandbox** (`sandbox: true`), além do `contextIsolation` ligado e do `nodeIntegration` desligado.

## Correções

- Se a instalação do bloqueio de requisições de uma tela falhar uma vez, a tentativa seguinte instala o bloqueio de novo (antes a tela podia ficar sem ele).

## Por trás

- Modo Linux: o app roda no Linux (inclusive num servidor sem tela) e gera um `.deb`. O `.deb` não é publicado nos releases: no Linux a atualização é manual (veja o README).
- CI no GitHub Actions: testes em Windows e Linux e teste de fumaça do app em Linux a cada PR.
- Releases montados e publicados pelo GitHub Actions, num Windows, com o `latest.yml` conferido contra o instalador.

## Instalar

Quem já tem o IdleHub no Windows recebe esta versão sozinho: o app baixa em segundo plano, avisa e instala ao reiniciar. Para instalar do zero, baixe `IdleHub-Setup-0.3.0.exe` abaixo. O instalador não é assinado, então o Windows pode mostrar o aviso do SmartScreen.
